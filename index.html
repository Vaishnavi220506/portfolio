06 06 / Compilers & systems

ModelForge

A C++17 tensor compiler for small neural-network models that checks every optimization before it keeps it.

It loads .mforge models, rewrites the graph, and emits standalone C++ inference code. A built-in validator, Guardian-APC+, tests each rewrite with inputs placed on the model’s ReLU boundaries and rolls back any change that alters behaviour, with a replayable counterexample.

  • 99.2% of injected faults caught with 128 inputs
  • Shrink check for float16, int8, int4 and pruning
  • Model diff checker with terminal and browser dashboards
  • C++17
  • CMake
  • Compilers
  • ML systems
